About the Project

This project is a Machine Learning-based predictive maintenance system that estimates how long a vehicle can operate before failure. It analyzes sensor data such as engine temperature, oil pressure, vibration, and service history to detect early signs of mechanical issues.

Key Features

📊 Sensor-Based Analysis

Uses real-time vehicle sensor inputs.

⚙️ ML Model

Decision Tree algorithm for prediction.

⚠️ Early Failure Detection

Identifies potential breakdown risks early.
